# XM ad image filenames

Place your two ad image files in this folder with these exact names:

- `xm-banner-wide.jpg` for the large banner used across pages.
- `xm-banner-sidebar.jpg` for the sidebar ad card.

These filenames are referenced by the theme partials:

- `partials/ad-banner.hbs`
- `partials/ad-sidebar.hbs`
